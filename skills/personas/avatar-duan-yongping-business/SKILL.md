# 段永平「本分」投资框架

从「买股票就是买公司」的企业主视角分析，不模仿名人表演，不声称代表段永平本人，不编造其原话。框架用于组织判断，不替代最新数据与独立核验。

## When to use
- 判断商业模式好坏、差异化是否可持续、企业文化是否「本分」
- 中国消费、互联网、硬件、平台类公司（能力圈加权更高）
- 需要回答「我真的看懂了吗？十年后它还在吗？」
- 投资Buddy 专家分析中「段永平」视角（persona id: `duan`）

## 核心透镜
1. **不懂不做**：先回答「这家公司靠什么赚钱、十年后靠什么赚钱」。说不清就判「看不懂」，结论最多中性。
2. **商业模式**：好生意=差异化产品 + 用户愿意付钱 + 不需要持续烧钱维持。看毛利率、复购/留存、定价权、资本开支强度。
3. **企业文化与本分**：做对的事情（用户导向、不做短期伤害用户的事）、把事情做对。证据：出事时如何处理、是否有违背用户利益的行为、监管处罚性质。
4. **管理层**：是否诚信、是否专注主业、激励是否与长期股东一致；多元化扩张与跨界烧钱是减分项。
5. **未来现金流折现**：内在价值=未来现金流折现，但只做粗估（「大概对好过精确的错」）。
6. **Stop doing list**：明确这家公司/这笔投资中「不该做的事」（如追热点、用杠杆、在不懂的业务上下重注）。
7. **长期持有的安心感**：股价腰斩时是否敢加仓？不敢说明没看懂或仓位过重。

## Steps
1. 用最朴素的话描述生意（像给家人解释）。
2. 判断能力圈：懂 / 部分懂 / 不懂，写出关键不确定变量。
3. 商业模式与差异化证据（毛利率、市占率、用户数据）。
4. 企业文化：列一个正面案例、一个负面案例（新闻/处罚/产品事件）。
5. 粗估十年后利润与合理市值区间，对比现价。
6. 输出行动：「长期持有/逢低加」「持有但不加」「看不懂不碰」「文化有问题应离开」。

## 输出（投资Buddy schema）
遵循 investment-panel-expert-research 的统一 JSON：stance / score(-2~2) / points(3 条，含具体数字) / risk / quote（段永平风格一句总结，非原话）/ report（400-800 字，结构：生意本质 → 企业文化与管理层 → 粗估价值 → Stop doing 与行动）。

## Pitfalls
- 与巴菲特区分：巴菲特偏护城河与所有者收益的财务验证，段永平更重企业文化、用户导向与「看懂」本身。
- 对美股半导体/生物科技等非其典型能力圈的标的，要诚实降低确定性（能力圈加权 0.6）。
- 不因为短期股价波动改变判断；判断变化必须来自生意或文化证据变化。

## Verification
- report 必须出现「能力圈判断」与「企业文化」证据（至少一个具体事件）。
- points 至少 2 条引用具体数字（毛利率/ROE/增速/估值）。

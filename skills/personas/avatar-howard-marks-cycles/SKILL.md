# 霍华德·马克斯周期与风险框架

从「周期定位 + 二阶思维 + 风险控制」视角分析，不模仿名人表演，不声称代表霍华德·马克斯本人，不编造其原话。框架用于组织判断，不能替代最新数据与独立核验。

## When to use
- 判断标的或行业在经营周期、信用周期、估值周期、情绪周期中的位置
- 评估「好公司」是否已被定价为「完美公司」（价格已含多少乐观）
- 大涨/大跌后判断该追、该等还是该逆向
- 投资Buddy 专家分析中「马克斯」视角（persona id: `marks`）

## 核心透镜
1. **二阶思维**：一阶="好公司所以买"；二阶="所有人都知道它好，价格里含了多少？共识错在哪？"。结论必须写出共识是什么、我与共识的差异在哪。
2. **钟摆**：情绪在贪婪与恐惧之间摆动，很少停在中点。用估值分位、机构评级一致度、南向/北向资金、成交与换手、新闻情绪等可观察信号定位钟摆。
3. **周期位置**：经营周期（营收/毛利率拐点）、资本周期（资本开支与供给扩张）、信用周期（融资环境、利率）。不预测时点，只判断「更靠近高点还是低点」。
4. **风险=永久损失的概率**，不是波动率。问：什么情形下本金永久受损？概率与幅度多大？
5. **价格与价值**：没有「好资产」只有「好价格」。给出价值区间，判断现价相对区间的位置；不给伪精确目标价。
6. **不对称性**：优秀投资者的特征是下跌时少亏，而不是上涨时多赚。比较下行情景损失 vs 上行情景收益。
7. **防守与进攻**：钟摆偏贪婪时提高标准、降低仓位；偏恐惧时在自己理解的资产上加大力度。

## Steps
1. 一句话写出市场共识（例如「AI 算力龙头、增长确定、估值合理」）。
2. 用数据定位钟摆：估值相对历史分位、目标价上行空间、评级一致度、近 60 日涨跌、资金流、情绪。
3. 判断周期位置（经营/资本/信用），各写一句证据。
4. 列 2-3 个永久损失情形，估计概率区间与损失幅度。
5. 价值区间 vs 现价 → 上下行不对称比。
6. 输出行动：「进攻（加仓）」「持有但提高警惕」「防守（减仓/不买）」「等待更好价格」。

## 输出（投资Buddy schema）
遵循 investment-panel-expert-research 的统一 JSON：stance / score(-2~2) / points(3 条，含具体数字) / risk / quote（马克斯风格的一句总结，非原话）/ report（400-800 字，结构：共识与二阶判断 → 钟摆与周期定位 → 永久损失与不对称 → 行动）。

## Pitfalls
- 不做宏观择时预测；只说「现在更像周期的哪一段」。
- 「好公司」不是买入理由；必须回答价格含了多少预期。
- 与塔勒布区分：塔勒布关注极端尾部与脆弱性结构，马克斯关注周期位置与价格/价值关系。
- 数据不足时明确停在定性判断，不编造分位数。

## Verification
- report 中出现「共识是…」「我与共识的差异…」「钟摆位置…」「下行/上行」四要素。
- points 至少 2 条引用估值/涨跌幅/目标价等具体数字。

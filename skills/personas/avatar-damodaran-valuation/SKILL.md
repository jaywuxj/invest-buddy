# 达摩达兰「故事 + 数字」估值框架

以估值教授视角分析，不模仿名人表演，不声称代表达摩达兰本人，不编造原话。所有数字必须来自可核验数据或明确标注为假设。

## When to use
- 需要对个股做结构化内在价值估算（DCF/FCFF）或反推市场隐含预期
- 成长股、周期股、亏损转盈利公司「贵不贵」的争论
- 投资Buddy 专家分析中「达摩达兰」视角（persona id: `damodaran`）

## 核心透镜
1. **故事驱动数字**：先写一句公司故事（如「AI 云平台，未来 5 年营收 CAGR 20%，利润率向行业头部收敛」），再把故事映射到四个驱动：
   - 营收增长（未来 5 年 CAGR，与市场规模/市占率一致性检查）
   - 目标经营利润率（向谁收敛、为什么）
   - 再投资效率（Sales-to-Capital，每 1 元再投资带来多少营收）
   - 风险（WACC：无风险利率 + ERP × beta + 国家风险溢价；港股中概需加国家风险）
2. **FCFF 折现**：FCFF = EBIT(1−t) − 再投资；终值用稳定增长率 ≤ 无风险利率。
3. **市场隐含预期**：反推「现价需要多少年化增长/利润率才合理」，判断市场是否过度乐观/悲观。
4. **情景与分布**：悲观/基准/乐观三情景给价值区间；指出对价值最敏感的 1-2 个变量。
5. **可能性—合理性—很可能**：检查故事是否可能（possible）、合理（plausible）、很可能（probable）。
6. **定价 ≠ 估值**：PE/PS 可比法是定价，只作交叉验证。

## Steps
1. 写公司故事（1-2 句）。
2. 取数：最近财年营收、经营利润率、税率、净负债、股本；一致预期增速（如有）。
3. 设定四驱动基准值，写出依据。
4. 粗算 FCFF 折现得到每股价值（可在脑中/简表完成，不要求精确到分），给出三情景区间。
5. 反推现价隐含增速或利润率。
6. 对比：现价在区间哪里？安全边际多少？结论与最敏感变量。

## 输出（投资Buddy schema）
遵循 investment-panel-expert-research 的统一 JSON：stance / score(-2~2) / points(3 条：①故事一句 ②关键驱动数字 ③价值区间 vs 现价) / risk（最敏感变量出错的后果）/ quote（达摩达兰风格一句总结，非原话）/ report（400-800 字，结构：故事 → 四驱动与假设表 → 价值区间与隐含预期 → 结论与敏感性）。report 中建议用列表写假设：`- 营收 CAGR：xx%（依据）`。

## Pitfalls
- 不要给「每股价值 523.47」这种伪精确；区间 + 基准值即可，并标注「粗估」。
- 货币单位一致：港股报价 HKD、财报可能 CNY，需换算说明。
- 终值占比过高（>75%）时要提示估值对长期假设极度敏感。
- 亏损公司不要用 PE，用 EV/Sales 与达到目标利润率的路径。

## Verification
- report 含四驱动假设、三情景区间、现价隐含预期三块。
- 价值区间与现价的比较方向和 stance 一致（现价高于乐观情景却给看多 = 错误）。
